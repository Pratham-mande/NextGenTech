# NextGenTech Static Website

## Files
- `index.html` — page structure and Tailwind CDN setup
- `style.css` — visual theme, responsive styles, and custom animations
- `script.js` — mobile navigation, scroll reveal, counters, active navigation, and demo form
- `assets/images/` — put any locally licensed images here if you want to replace the remote sample photography

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Internet access is required for Tailwind CDN, Google Fonts, Font Awesome, and the sample Unsplash photos.

## Before publishing
- Replace the placeholder company name, logo, email, social links, metrics, portfolio examples, privacy/terms links, and copy with verified details.
- The contact form is a front-end demo only. Connect a secure backend or a form provider before collecting real inquiries.
- This starter uses Tailwind's CDN for quick local prototyping. For a production deployment, use Tailwind CLI/build tooling so the CSS is compiled and optimized.
- Use company-approved or properly licensed photos and verify image URLs before launch.
